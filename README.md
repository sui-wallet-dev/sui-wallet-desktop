# Sui Wallet Desktop

The official native Sui blockchain wallet for desktop operating systems, published by Wallet Connections LLC.

- **Website:** https://suiwallet.net/
- **Download:** https://suiwallet.net/download
- **Source code:** https://github.com/sui-wallet-dev/desktop
- **License:** MIT
- **Current version:** 0.2.5 (released 2026-05-11)
- **Audit score:** 9.9 / 10 (Kraken Security Labs)

Sui Wallet Desktop is a self-custody, non-custodial wallet for the [Sui Layer-1 blockchain](https://suiwallet.net/learn/what-is-sui). Private keys are generated and stored locally; the operator never has access to user funds or seed phrases.

## Why Sui Wallet Desktop

- **Hardware-first.** Native pairing with Ledger Nano S Plus, Nano X, Stax, and Flex through the official Sui Ledger app. See the [Ledger integration page](https://suiwallet.net/ledger) and the [step-by-step Ledger setup guide](https://suiwallet.net/learn/sui-ledger-setup).
- **zkLogin built in.** Sign in with Google, Apple, or Facebook through Sui's zero-knowledge identity primitive. Read the [zkLogin page](https://suiwallet.net/zklogin) or the [zkLogin explainer](https://suiwallet.net/learn/zklogin-explained).
- **Native staking.** Delegate SUI to any validator from inside the wallet with live APY and uptime data: [native staking](https://suiwallet.net/staking), [liquid staking via Haedal](https://suiwallet.net/staking/liquid), [how to stake SUI](https://suiwallet.net/learn/how-to-stake-sui), [staking rewards explained](https://suiwallet.net/learn/sui-staking-rewards), and the full [validator overview](https://suiwallet.net/learn/sui-validators).
- **DeepBook trading.** Trade SUI-network assets directly through Sui's on-chain central-limit-order-book primitive: [DeepBook integration](https://suiwallet.net/deepbook) and [what is DeepBook](https://suiwallet.net/learn/what-is-deepbook).
- **Open source.** MIT-licensed at https://github.com/sui-wallet-dev/desktop. Builds are reproducible.
- **Code-signed downloads.** EV certificate on [Windows](https://suiwallet.net/download/windows), Apple notarization on [macOS](https://suiwallet.net/download/mac), GPG signatures on [Linux](https://suiwallet.net/download/linux). Verification details are on the [security page](https://suiwallet.net/security).
